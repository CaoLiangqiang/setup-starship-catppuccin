# Official Sources

Re-check version-sensitive behavior before changing scripts or assets.

- Starship installation: https://starship.rs/guide/#step-1-install-starship
- Starship shell initialization: https://starship.rs/guide/#step-2-set-up-your-shell-to-use-starship
- Starship configuration: https://starship.rs/config/
- Catppuccin Powerline preset: https://starship.rs/presets/catppuccin-powerline
- WinGet Starship package: https://github.com/microsoft/winget-pkgs/tree/master/manifests/s/Starship/Starship
- Nerd Fonts patched Cascadia Code: https://github.com/ryanoasis/nerd-fonts/tree/master/patched-fonts/CascadiaCode
- Nerd Fonts licensing: https://github.com/ryanoasis/nerd-fonts/blob/master/LICENSE
- Cascadia Code font license: `assets/fonts/OFL.txt`
- Windows Terminal profile settings: https://learn.microsoft.com/windows/terminal/customize-settings/profile-general
- Windows Terminal appearance settings: https://learn.microsoft.com/windows/terminal/customize-settings/profile-appearance
- Windows per-user font registry: https://learn.microsoft.com/windows/apps/design/signature-experiences/typography
